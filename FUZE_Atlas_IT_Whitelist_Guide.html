Authentication & Access Control

  • Authentication: JWT-based session tokens stored in HTTP-only, Secure, SameSite cookies
  • Password Security: bcrypt hashing with 12-round salt
  • Session Duration: 7-day expiry, server-verified on every request
  • Role-Based Access: Brand partners see only their own data — isolated by brandId
  • Rate Limiting: Login attempts capped at 5 per 15 minutes per IP
  • No Third-Party Auth: No OAuth, no social login — direct credential authentication only

Data Handling

  • Data at Rest: PostgreSQL database encrypted at rest (AWS/Railway)
  • Data in Transit: TLS 1.2+ on all connections
  • File Storage: AWS S3 with pre-signed URLs (time-limited access)
  • Data Isolation: Multi-tenant with strict row-level filtering by organization
  • PII: Limited to contact name and email for account access
  • No tracking cookies: Only functional session cookie used

Common Corporate Firewall Issues

Why access may be blocked

Some corporate security systems block access to *.vercel.app domains because:

  • Category filtering: Some web filters categorize vercel.app as "Technology/Cloud Hosting" and block the entire category. Your IT team should add fuzeatlas.vercel.app as an explicit allow-list exception.
  • SSL inspection: Corporate SSL inspection proxies may interfere with our HSTS headers. The domain should be added to the SSL inspection bypass list.
  • Geographic IP blocking: If your firewall blocks US-origin traffic, Vercel's edge network serves from the nearest PoP. Whitelisting the domain (not IP) is recommended.
  • Content Security Policy conflicts: Corporate browser extensions may conflict with our CSP headers. Try accessing from an incognito/private window to test.

Quick Test

Ask the user to visit https://fuzeatlas.vercel.app/api/health — if this returns a JSON response, the connection works. If it times out or shows a block page, the domain needs whitelisting.

Vercel IP Ranges (for IP-based firewalls)

If your firewall requires IP-based rules rather than domain-based, Vercel publishes their IP ranges. However, these change frequently, so domain-based whitelisting is strongly recommended.

Current Vercel IP documentation: https://vercel.com/docs/security/ip-addresses
